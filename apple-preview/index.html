Try Apple street photos

Use your Apple Developer membership to preview Look Around directly on the property tiles.

  1. Open Apple Maps tokens and click +.
  2. Select MapKit JS. For this local test, allow localhost if you choose a domain restriction.
  3. Copy the generated Maps token and paste it below.

This saves the token in this browser tab’s session storage. It does not change the live website. Use a generated web token, never a private key or Apple account password.
