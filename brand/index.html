The search-bar a

Three takes on a Find a Crib wordmark where the standalone a isn't set in type at all — it's drawn as a search field. The left end is the bowl of the a with the magnifier sitting concentric inside it, the bar is the stretched counter, and the flat right terminal is the a's stem.

“Find” and “Crib” stay in Oxanium 800 — the face the site header already self-hosts — so the mark and the running wordmark are one typeface. Every file is outlines, no font dependency, generated by scripts/make_logo.py.

A — Wide (closest to the reference)

wordmark-wide.svg

The bar carries the lockup. Best for the OG image, signage and anywhere it gets to be the only thing on the page.

B — Compact (header-safe)

wordmark-compact.svg

Same construction, bar pulled in so the counter still opens up at 22px in the topbar.

C — Pill (both ends round)

wordmark-pill.svg

Prettier and more obviously a UI control — but with no stem it reads as a chip dropped between two words rather than as a letter. Included because it's the call worth making deliberately.
