Bookings — the money signal

Estimates and consultations booked on the site. Counts and dates only: no name, phone or address reaches this page. Our own test bookings are excluded and reported separately. A tel: tap is invisible here — the site ships no beacon, so calls and texts are uncounted, not zero.

Shoppers & orders — the money signal

An order is counted only when Shopify’s checkout reports it complete inside the app, and only for signed-in shoppers — a guest’s orders stay on their phone until they sign in. The money goes straight to each brand; Marracat never holds it. Counts only: no shopper’s name, email or order reaches this page.

iPhone app — who is opening it?

From marracat.com’s server log. The app names itself and its build on every request and checks for a newer catalog once per cold launch, so a launch is that check. It sends no device id, so a device is an address + build + iOS version — a phone that changes network counts again.

Web storefront — marracat.com

A visitor is a browser that loaded the catalog, which only happens once the storefront’s JavaScript runs — a scraper that takes the page and leaves is never counted. Bots and datacenter addresses are removed.

What the growth engine shipped

The 6am loop measures yesterday, judges what’s running, and builds.
Visitors are counted from the site’s own nginx log — not from a JavaScript tag, so ad-blockers can’t hide them. Bots, Eric’s IPs and your own devices are removed: open nemoseamlessgutter.com/?owner=1 once on any phone or laptop you test from and it stops being counted there permanently, on every network it uses (?owner=0 undoes it). Otherwise a “visitor” is one IP + browser per day, since the site sets no tracking cookie: switching from wifi to cell counts twice, and a whole office behind one router counts once.
